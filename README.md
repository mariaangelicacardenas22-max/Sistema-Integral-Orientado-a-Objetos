# Sistema-Integral-Orientado-a-Objetos
Sistema Integral de Gestión de Clientes, Servicios y Reservas

# Sistema
- Sin uso de bases de datos
- Capaz de gestionar clientes
- Servicios y reservas

# Empresa
Software FJ

# Servicios
- Reservas de salas
- Alquiler de equipos
- Asesorías especializadas

# Principios implementados
- Abstracción
- Herencia
- Polimorfismo
- Encapsulación
- Manejo avanzado de excepciones

# Incluye
- Clases abstractas
- Clases derivadas
- Métodos sobrecargados
- Manejo de listas internas
- Validaciones estrictas

# Ejecucion
Requiere Python 3. Desde la carpeta del proyecto:

```bash
python main.py
```

Los eventos y errores quedan registrados en `logs/software_fj.log`

# Archivos
- `main.py` Simulación de operaciones válidas e inválidas
- `entidad.py` Clase base del sistema
- `cliente.py` Gestión de clientes
- `servicios.py` Gestión de servicios
- `reserva.py` Gestion de Reservas
- `excepciones.py`Excepciones personalizadas
- `gestor.py` Listas internas y captura de errores
- `logger.py` Configuración del archivo de logs
